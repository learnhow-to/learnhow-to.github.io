1. Buka folder `C:\Users\fatun\.gemini\antigravity\scratch\fatun-portfolio\` di File Explorer.
2. Cukup **klik dua kali (double-click)** pada file `index.html`.
3. File akan langsung terbuka di browser (Google Chrome, Edge, dll) dengan tampilan penuh dan animasi aktif!

> **Tips Cepat lewat PowerShell / CMD:**

## 🌐 Cara Mempublikasikan ke Internet Secara GRATIS (GitHub Pages)

Kamu bisa memiliki website online dengan alamat resmi: **`https://learnhow-to.github.io`** tanpa bayar sepeser pun!

### Langkah 1: Buat Akun & Repository di GitHub
1. Buka [github.com/new](https://github.com/new) dan pastikan sudah login ke akun **`learnhow-to`**.
2. Beri nama repository: **`learnhow-to.github.io`**.
3. Pilih opsi **Public**.
4. Klik **Create repository**.

### Langkah 2: Upload File Portfolio
1. Di halaman repository yang baru dibuat, klik **"uploading an existing file"**.
2. Tarik (drag and drop) semua file dari folder `fatun-portfolio` (`index.html`, `style.css`, `script.js`, `README.md`, `case_study_droidmirror.md`).
3. Klik tombol hijau **"Commit changes"**.

### Langkah 3: Aktifkan GitHub Pages (Otomatis Aktif)
1. Karena nama repository adalah `<username>.github.io`, GitHub Pages akan langsung aktif secara otomatis!
2. Jika menggunakan nama repository lain (misal: `portfolio`):
   - Masuk ke menu **Settings** -> **Pages** di repository tersebut.
   - Pada bagian **Build and deployment**, pilih Source: **Deploy from a branch**.
   - Pilih Branch: `main` dan folder `/ (root)`.
   - Klik **Save**.
3. Tunggu 1–2 menit, website kamu sudah live di internet dan bisa diakses oleh siapa saja di seluruh dunia!
